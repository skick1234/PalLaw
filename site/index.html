PalLaw Rules Studio

Create Palworld server rules with a free visual map editor. Draw regions, configure combat rules, validate your configuration, and export PalLaw.json for the PalLaw mod.

Draw regions on the Palworld map

Use the World and World Tree maps to define polygon regions. Assign modes and schedules, configure player actions and combat permissions, and edit player messages.

Validate and export your rules

Import an existing rulebook or create a new one. Studio validates your configuration before exporting PalLaw.json. Install the PalLaw mod to enforce the rules on your server.

Your configuration stays in your browser

No account, configuration uploads, or telemetry. Enable JavaScript to use the interactive editor.
